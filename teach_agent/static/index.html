先看看是不是你想要的

教学方案

确认方案即可制作，也可以说一句修改要求。

查看或手动修改详细方案（可选）

这是旧版方案。可在下方点“帮我改方案”，补齐需求与难点分析、逐步教学设计。

围绕学生理解来设计

根据你的需求，分析知识点的理解难点，再安排解决办法和讲解顺序。你可以直接修改，不需要提供学生作答记录。

逐步讲解与互动顺序

每步围绕一个问题，操作产生证据，讲解帮助解释证据。可以直接修改或上下移动，确认后才会制作。

动画画面

时长由各段相加。要增删或重新编排镜头，可在上方描述修改要求。

两力合成动画参数

只适用于两力合成主题。修改其他动画主题不会自动变成这个模板。

课堂作品

互动文件用浏览器打开；含视频的离线包请先完整解压。已检查内容以当前版本报告为准。

如需改变教学目标或讲解结构，请先返回调整方案并重新确认。

设置

正在连接

生成时会把教学需求、方案和相关素材发给你配置的模型服务。密钥仅保存在本机配置中。

动画制作设置

动画使用本机 Sol 工作流，需要安装 Codex CLI 并通过 codex login 登录 ChatGPT；沿用已有 Manim 环境。需求、方案及检查画面会发给该模型，生成的场景代码在本机执行。复杂公式还需要 LaTeX。

连接本机工作台

请使用启动器打开，或填入本机数据目录中 session-token 文件的访问码。

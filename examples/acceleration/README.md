# 加速度的影响因素

用户指定主题后制作的完整离线互动课件，供直接体验。不是生成流水线的自动验收结果。

四个环节：质量不变改变合力、合力不变改变质量、自由探究、理解检验。两车同时出发，使用相同时间、相同位移刻度和速度坐标；支持预测、暂停、慢放、时间回看、归纳和复位。自由探究允许设定共同初速度，展示合力为零时可保持匀速运动。

模型为水平恒合力、恒质量、无摩擦：a=F/m、v=v0+at、s=v0t+at²/2，0≤t≤2 s。箭头长度与合力成正比，质量显示为车与载物的总质量；动画播放倍率只改变播放速度，不改变物理时间的含义。

小车 SVG 保留 Open Lab Components `phy.mechanics.cart.dynamics` 的原始几何，课件控制颜色与砝码显示。完整原许可随 HTML 附带。KaTeX、字体和交互辅助脚本全部内联。

构建：在项目根目录运行 `python examples/acceleration/build.py`。输出为 `dist/examples/acceleration/加速度的影响因素.html`，复制这一个文件即可离线使用。

验证：`python examples/acceleration/verify.py`，使用独立浏览器打开本地成品并阻断外部请求，核对播放暂停、物理读数、锁定条件、改参数归零、匀速运动、公式、预测、判分、完整复位和三种屏幕宽度。检查结果与截图保存在成品目录。独立内容/代码复核发现的复位按钮状态问题已修复，回归先失败后通过。未在另一台物理电脑实测。

## 配套讲解动画

已补充约93秒、1280×720、30fps的Manim MP4，包含Windows本机合成的中文配音和画面要点字幕。画面依次覆盖合力、质量、匀速运动的零加速度、合力与质量同时翻倍。原小车几何的MIT许可保留在HTML、MP4元数据及独立声明文件中。

HTML内嵌完整MP4，点击顶部“讲解视频”播放；复制一个HTML仍然可以离线看视频。单独MP4及完整ZIP在成品目录。配音脚本make_narration.ps1使用本机Windows语音；animation_scene.py用已有Manim环境渲染，package_video.py写入来源声明，再运行build.py嵌入。render-local忽略于Git，不打包运行环境。

成片抽检5、22、44、66、84秒画面，修复图表标签重叠；音视频流和实际离线浏览器播放通过验证。网页视频播放会暂停实验，关闭播放器停止配音。

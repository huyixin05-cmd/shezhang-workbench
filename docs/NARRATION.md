# 自然讲解配音

在网页「设置 → 讲解配音」中填写语音服务地址、语音模型、音色和独立密钥，点击「保存配音设置并试听」。试听包含提问后的两秒思考停顿。满意后勾选「动画使用自然语音配音」并保存。网页和 WorkBuddy 使用同一配置；无需每段讲稿都找老师确认。

目前适配 **OpenAI 兼容的 `POST /audio/speech`**，发送 `model`、`voice`、`input`、`response_format: wav`。服务需支持 WAV 音频响应。只有服务支持 `instructions` 参数时才勾选语气指令。这里指接口兼容性，不表示所有语音厂商的原生接口都能直接接入。实现参数依据 [官方语音接口指南](https://developers.openai.com/api/docs/guides/text-to-speech)。

语音服务使用自己的额度，与 WorkBuddy 对话额度分别计算。讲稿发送给该语音服务；密钥保存在本机 `.data/config.json`，不回传浏览器、不写入作品或导出的工程。不要把密钥粘贴到聊天。也可使用环境变量 `TEACH_SPEECH_URL`、`TEACH_SPEECH_MODEL`、`TEACH_SPEECH_VOICE`、`TEACH_SPEECH_API_KEY` 设置连接信息；开启配音与语气指令仍由本机设置控制。

## 制作过程

1. 复用已确认方案，写口语讲稿：围绕理解难点，先观察或预测，再比较、解释。公式改成可听懂的中文，保留成立条件。
2. 自动复核科学内容、讲解顺序、口语表达和提问与答案的关系。老师的后续修改要求同样传入讲稿与复核步骤。
3. 按完整短句或紧密相连的两句合成，测量实际音频长度。相同服务、音色、文本与语气指令在本次作品内复用已合成文件。
4. 安排提问后至少 2 秒、观察后至少 1 秒的停顿。超时或出现过长空白时自动改写讲稿，最多两轮；不加速、不裁切语音、不暗中延长确认过的视频时长。
5. 根据实测时间线生成画面，逐句对齐动作。预览和清晰版都检查提示顺序、音轨存在、尾句完整、总时长，并对照时间线抽帧复核。

语音服务失败会明确报错，不会悄悄改用系统朗读。未启用配音时保留原来的无声动画功能。场景修复复用已合成音轨；重新修改作品时根据新的要求重写讲稿。

## 输出与限制

MP4 内含配音，播放不需要联网、语音密钥或 Manim。画面标有「AI 配音」。编辑工程包含讲稿、实测时间线、配音 WAV 和复核记录，路径相对工程目录。解压后在 `animation` 目录中使用 Manim 可继续编辑渲染。

程序能检查有效音频、明显静音/削波、时长与提示顺序；文本模型和图片复核**不能证明声音听起来像真人老师**。自然度、发音与情绪仍需试听所选服务和音色。`narration-report.json` 明确记录 `listening_reviewed: false`。目前没有针对真实云服务音色的验收结果；既有加速度示例仍是旧系统配音，需配置服务后重新制作。

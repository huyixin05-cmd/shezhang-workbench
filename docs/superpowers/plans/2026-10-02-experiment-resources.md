# 实验资源收录与交互改进

依据用户提供的《理化互动实验源码资源清单》执行：可再分发的资源保存到项目供使用；借鉴实验交互，保留统一器材视觉。

1. 核对清单全部仓库的实际许可证及运行要求。明确已收录、仅参考、许可待核实；不把公开源码当作授权。
2. 保存可用源码快照、原始许可证/声明、固定提交和文件哈希。独立实验原样保存，不把 GPL 实验拼进 MIT 生成页面；无清晰授权的内容只记录链接和功能观察。
3. 从实际源码提炼拖动、参数操作、测量、时序和复位规则。按主题将简短规则加入现有教学设计/制作/复核输入，两种模型入口共用。
4. 为资源提供本地目录和 MCP 查找/导出入口，明确运行要求；不在首页堆组件入口。接入可复用的交互辅助实现，并做真实操作验证。
5. 核验快照完整性、离线导出、提示词接入和回归测试；独立审查后更新发布包与说明。
